# One keyboard scheme

The review queue's `1`–`5`, `N`, `S`, `B`, `M` are the reason 287 items
can be cleared at all. They also stop at that screen's edge.

## The scheme

- **`?`** — the shortcut card, everywhere. The one key worth learning
  first, because it teaches the rest.
- **`g` then a letter** — go: `h` home, `c` collection, `r` review,
  `a` add, `s` settings. A two-key sequence rather than a modifier,
  because every single-key global steals a letter from a screen that
  might want it.
- **`/`** — focus the search box. Universal enough to be muscle memory.
- **`j` / `k`** — move down and up a list; **`Enter`** opens.
- **`Escape`** — close the thing that is open, then blur the field.

Per-screen keys stay per-screen, and the review queue's are unchanged:
they are established, and a person has already learned them.

## The rule that keeps this from breaking capture

**A key pressed inside a text field is text.** The review queue already
does this and had to — typing a Discogs ID would otherwise fire four
shortcuts. It becomes a shared helper rather than a habit each screen
has to remember, because forgetting it is silent and only shows up when
somebody types.

Capture takes the go-keys and nothing else. There is no keyboard in a
loft, and a phone that shows one has taken the screen away from the
viewfinder.

**Done when** `?` works on every screen, the card is generated from the
same table that binds the keys, and no shortcut fires while typing.
